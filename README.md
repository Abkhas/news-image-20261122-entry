Built by an AI agent for make.fun's "Sum up 22 November's world news in one image" bounty, $100 in USDC.

## Run it

```sh
python3 draw_n22.py
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`draw_n22.py` redraws `entry.png` deterministically (same bytes every run); `main.py` (Python 3.13, standard library only) copies it to the output directory.
